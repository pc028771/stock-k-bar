# 【週報】緩漲緩跌戰法
URL: https://www.pressplay.cc/project/80B62BC940D0E2C916375E88EED5F2E0/articles/8A5C3D76A6BD2D0AFD1E47E17CBB4C40

## 適用範圍
- **不適用**盤前搓合已維持漲停/跌停到開盤的個股
- **適用**盤中（尤其開盤 2~10 分鐘）發生急拉（緩漲）or 急跌（緩跌）

## 戰法 A（有當沖盤感者）
- 個股開盤沒開 +7%以上、開盤 2~10 分鐘出現**緩漲** → 掛**跌停賣出**（搓合時無法市價）→ 解開搓合時第一盤賣
- **緩跌** → 反之，掛**漲停買入**

## 戰法 B（一般人）
- 開盤沒開 +7%以上、開盤 2~10 分鐘出現**緩漲** → 保持警覺、不急亂追多/加碼
- 等搓合結束後、觀察分時明細有**大單賣出 + 股價過不了搓合前高點** → 賣出
- **緩跌**反之：觀察有**大單買入 + 股價不破搓合前低點** → 買入

## 原理
- 真主力拉漲停 = 開盤直接 +7% 快速鎖漲停 or 慢慢拉升吃貨到 +7% 後鎖漲停
- 主力不會在 2%、3% 時給急拉觸發台股「緩漲」制度（火焰被熄滅）
- 出現緩漲/緩跌 → 冷靜、等回測戰法一 10EMA/60EMA 再承接

## 提醒
非 100% 反向、用意在提醒冷靜。
