# 【週報】開盤後的快速選股技巧與盤中一鍵見強弱股

## 開盤後自選股/新聞股觀察要點
1. **大戶賣超先剔除**、只看買超
2. 看**開盤就開在上關價之上**、回踩上關價又勾上時可留意（類分歧概念）
3. **開盤往上要撞關鍵價** → 反而要小心（撞不過去、隔日沖客會丟）
   - 尤其開盤撞上關 → 隔日沖客會丟
4. 切 **1 分 K 戰法一** or **5 分 K 戰法一** 確認停損可接受（1分=當沖、5分=可留倉）
5. **反向戰法**：全大戶賣超 + 撞關鍵價/均線撞不過 + 破戰法一 → 可空

## 觀念
- 做多要找符合戰法一（至少 1 分 K 符合）、做空要找破戰法一
- 別預設高點空強勢股 = 賭博

## 盤中一鍵見強弱股（分類清單）
Frank 的分類清單範例：
1. **前一日日報處置注意個股**（飆股常從被處置注意開始，最快 5 日後進處置）
2. **主力買超 + 回檔趨勢線**個股（需大數據方案）
3. **近 3 天~1 週日報新聞個股**（都是強勢股、隨時回檔再噴）
4. **電子族群龍頭**：AI / 散熱 / 設備 / 台積概念 / 封測 / 記憶體
5. **非電子族群龍頭**：重電 / 營建 / 航運 / 金融 / 生技 / 遊戲

## 排序技巧
- **漲幅正向排序** → 最上面 = 當下最火熱、戰法完全符合
- **一直往上跳的** = 持續主力點火、N 字上攻底底高
- 確認**五檔戰法** + 戰法一/二 + 停損可接受 → 下單
- **反向做空**：跌幅反排、看誰一直往上跳 = 愈弱勢
