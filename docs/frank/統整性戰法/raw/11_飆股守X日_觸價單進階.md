# 【週報】飆股守 X 日 觸價單進階
URL: https://www.pressplay.cc/project/80B62BC940D0E2C916375E88EED5F2E0/articles/3ADE1A4461BD50F344F0BF92FD0F26AD

## 情境
很噴的股票每天股價在**布林頂之外**鎖漲停 → 每天守 5 日線觸價回吐空間太大 → 分批觸價設定。

## 分批觸價單設定（狂飆型飆股）
1. 鎖漲停 → 隔天用**鎖漲停戰法**處理；否則設**戰法一破 5 分 K 60EMA 下幾 tick** 分批出一點
2. 設**布林頂價位向下幾 tick** 出一點
3. 設 **(目前 5 日線價 + 目前股價) / 2** 出一點
4. 設**破前一日紅 K 一半** 出一點
