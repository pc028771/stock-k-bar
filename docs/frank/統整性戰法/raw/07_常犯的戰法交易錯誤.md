# 【週報】常犯的幾種戰法交易錯誤

## 常見錯誤清單

1. **日內盯著股價、強勢股急殺跟散戶起舞出貨**
   - 主力洗盤常急跌急漲嚇散戶
   - 強勢股急殺去看戰法一：多半點到 60EMA 附近就收腳拉回

2. **戰法一回 60EMA 就衝、忘看大戶買賣力**
   - 戰法一第 1 條規則：**至少大戶賣超收斂** 才能進場

3. **股價回 60EMA、沒等分歧就衝**
   - 至少等**後一根 K 收超過前一根 K**（慣性改變/日出型態）才進場
   - 不然易被 10EMA 壓著打 → 破戰法一

4. **左側急跌後看到 10EMA 上穿 60EMA 就急進**
   - 左側急跌後常橫盤震盪、才到右側上漲
   - 最保守 = 等 **60EMA 斜率 30~45 度上揚 + 股價回測 + 分歧**

5. **沿 10EMA 上漲不敢買、被 10EMA 壓著卻想抄底**
   - 順勢而為、勿逆勢添幻想

6. **大單一敲、K 爆量就追**
   - 忘記強股會回測 10EMA
   - 用**模擬單試單戰法**先衝動模擬買

7. **族群起漲不敢買大哥去買小弟、大戶賣超中的小弟**
   - **強者恆強**：資金+程式單專攻最強（有量才有價）
   - 小弟只是跟風、大哥跌小弟跌更慘
