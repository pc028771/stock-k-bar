# 【週報】簡易五檔判斷戰法（假掛單陷阱）
URL: https://www.pressplay.cc/project/80B62BC940D0E2C916375E88EED5F2E0/articles/F2361460D1F26FF71C2BCBA1EE0B31E0

## 觀念
散戶常看到委賣如高牆卻急拉、委買如高牆卻下殺 = 落入主力假單陷阱。

## 偏多判斷（該股符合戰法一時）
- 委賣**總數量** 遠大於委買總數量（**1.5x ~ 快 2x**）
- 委賣大單**不在第 1 檔**（最好大單掛在**第 5 檔最底下**）
- → 維持偏多、**不要急著拋售**

## 偏空判斷（該股不符合戰法一時）
- 委買**總數量** 遠大於委賣總數量（**1.5x ~ 快 2x**）
- 委買大單**不在第 1 檔**（最好掛在**第 5 檔最底下**）
- → 維持偏空、**不要急著抄底 V 轉**

## 原理
- 大戶假掛單騙散戶（掛非第 1 檔 → 不會真的成交）
- 假委賣：閃跳、數量異常多 → 股價敲上去時瞬間抽單 → 你賣一賣 → 股價上去 → 你追買 → 他倒貨
- 「一賣就噴、一買就跌」的原理
