## 核心戰法三選一（frank_core_v1）

Frank 全套戰法建立在**兩條 EMA**：`10EMA` + `60EMA`，配合大戶買賣力。三戰法差別只在 K 級別。

### `frank_1_short_ema_cross`（戰法一：短分時 EMA 分歧）

| Field | Spec |
|---|---|
| **K 級別** | 2m / 5m / 15m / 60m |
| **指標** | 10EMA + 60EMA（**必用 EMA、不用 MA**、避免騙線） |
| **前置條件** | 大戶**買超持續增加** OR 大戶**賣超收斂**（不可缺、raw/06） |
| **進場訊號** | 10EMA 上穿 60EMA + **60EMA 有斜率**（非橫向震盪） |
| **保守進場** | 60EMA 角度 ≥ 30°、回測 60EMA 後**分歧**（後一根 K 收超過前一根） |
| **停損** | (a) 10EMA 下穿 60EMA、OR (b) 60EMA 對照過去**左側爆大量城牆 K 低點**跌破 |
| **禁止情境** | 左側急跌段後首次上穿（易破再上、raw/07 錯誤 #4）→ 等 60EMA 上揚 30~45° 後回測分歧 |

### `frank_2_bollinger_upper_band`（戰法二：布林上軌區間）

| Field | Spec |
|---|---|
| **K 級別** | 還原日 K（避開除權息） |
| **指標** | 布林通道 + 20MA 月線（= 布林中軌） |
| **選股** | 月線上揚 + 股價維持在**布林上軌區間**（布林頂 ~ 中軌） |
| **進場** | 股價回檔到月線時切入 |
| **停損** | K 棒**連續兩日收盤跌破月線** OR 日落 |
| **加碼** | 回檔月線「回後買上漲」加碼 |
| **執行單** | 設**月線下方幾 tick 觸價單** |

### `frank_3_monthly_kd_macd`（戰法三：月 K KD + MACD）

| Field | Spec |
|---|---|
| **K 級別** | 月 K |
| **指標** | KD + MACD（DIF + MACD 值） |
| **進場** | KD 黃金交叉 + **DIF+MACD > 0**（同月進場） |
| **檢查頻率** | 每週一眼 |
| **停損** | 月 K DIF+MACD < 0（很少觸發） |
| **停利** | (a) 月 K KD > 70、(b) 月 K 高檔 KD 死叉、(c) 順向舒服想賣 |

**戰法副本**：權證取代現股 → 選**在外流通數大**（有大戶）+ 權證股價 < 大戶成本。警語：時間價值流逝 + 槓桿，凹單 → 龜苓膏。

## 衍生 detector

### `frank_daily_open_5m_key_level`（開盤 5 分 K 關鍵價位判斷）

**raw/01**

| Type | Condition | 進場/停損 |
|---|---|---|
| **偏強** | 第 1 根 5m 過前日高（非必) + 第 2 根 5m 過第 1 根 5m 高 | 關鍵價 = 第 1 根 5m 高；**若第 2 根 > +6%** 要能鎖漲停、否則快進快出；防守 = 破第 1 根 5m 一半，最低不破第 1 根低 |
| **偏弱** | 第 1 根 5m 無法過前日高 + 第 2 根 5m 無法過第 1 根 5m 高 | 關鍵價 = 第 1 根 5m 低；**若開盤 > +8%** 不做反向（怕嘎空鎖漲停）；反向防守 = 漲回第 1 根 5m 一半，最高不過第 1 根高 |

### `frank_15m_ema_trend_ride`（15m 兩條線中間戰法）

**raw/02** — 適合「當沖被巴、波段耐不住」中間族群。
- 15m + 10EMA + 60EMA
- **進場**：(a) 10EMA 上穿 60EMA、OR (b) 10EMA 回測 60EMA 後**分歧**（60EMA 有斜率動能大）
- **出場**：10EMA 下穿 60EMA
- **重進**：確認趨勢後等下次上穿

### `frank_taifex_two_ema`（台指期兩條線）

**raw/03**
- 日盤/夜盤：Frank 個人幾乎只做夜盤（程式單多）
- **趨勢判定**：訂閱動能趨勢圖 OR 台指 15m 戰法一 60EMA 斜率
- **進出**：2m 戰法一 / 5m 戰法一
- **停損**：破戰法一 OR 自設 30~40 點
- **避開**：15m 趨勢線走平 → 多空雙巴

### `frank_2_weekly_extended`（戰法二週 K 波段延伸）

**raw/04** — 上班族長抱版。
- 週 K + 20MA（20 週均線）
- **選股**：20 週均線上揚 + 股價回 20 週均線分歧 or 由下上穿
- **觀察點**：週 KD ≥ 20 金叉 + MACD ≥ 0 軸
- **進場切入**：日 K 飆股守 5 日 or 5m 戰法一鳥嘴/分歧
- **短線出場**：日 K 破 5 日（投信買超破 10 日）
- **中長波出場**：週 KD 當週死叉
- **絕對出場**：20 週均線開始下彎

### `frank_open_scanner_and_ranking`（開盤快選 + 盤中強弱股）

**raw/05**

**開盤自選股觀察**：
1. 大戶賣超剔除、只看買超
2. 開盤在上關價之上、回踩上關價又勾上 → 留意
3. 開盤往上撞關鍵價要小心（撞不過去 + 隔日沖客會丟）
4. 1m or 5m 戰法一停損可接受 → 下單
5. 全大戶賣超 + 撞關鍵價/均線不過 + 破戰法一 → 反向做空

**盤中排序**：
- 分類清單：處置注意個股 / 主力買超回檔趨勢線 / 近 3~7 日日報新聞 / 電子族群龍頭（AI 散熱 設備 台積 封測 記憶體）/ 非電子族群龍頭（重電 營建 航運 金融 生技 遊戲）
- 漲幅正向排序 → 最上面 = 最火熱、戰法完全符合
- **一直往上跳的** = 主力點火 N 字上攻底底高
- 反向：跌幅反排、一直往上跳 = 愈弱

### `frank_5tick_fake_order`（簡易五檔判斷 / 假掛單）

**raw/13**

| 情境 | 條件 | 判斷 |
|---|---|---|
| **符合戰法一** | 委賣總數量 > 委買 1.5x~2x 且大單**不在第 1 檔**（最好第 5 檔） | 偏多、不急拋售 |
| **不符戰法一** | 委買總數量 > 委賣 1.5x~2x 且大單**不在第 1 檔** | 偏空、不急抄底 |

**原理**：主力假掛單（非第 1 檔=不會真成交）→ 抽單製造反向。「一賣就噴、一買就跌」。

### `frank_slow_up_down`（緩漲緩跌）

**raw/14**

**適用範圍**：非盤前搓合已鎖漲跌停者、開盤 2~10 分鐘盤中發生。

| 情境 | 戰法 A（有盤感） | 戰法 B（一般） |
|---|---|---|
| 開盤 <+7% + 出現**緩漲** | 掛跌停賣出 → 搓合結束第 1 盤出 | 等搓合結束觀察分時明細：**大單賣出 + 過不了搓合前高** → 賣 |
| 開盤 >-7% + 出現**緩跌** | 掛漲停買入 | **大單買入 + 不破搓合前低** → 買 |

**原理**：真主力拉漲停 = 開盤直接 +7% 快鎖或慢慢吃到 +7% 再鎖、不會在 2~3% 時觸發緩搓機制。等回測 10EMA/60EMA 再承接。

### `frank_lock_limit_up_playbook`（鎖漲停戰略）

**raw/06 + raw/17 + 覆盤補強**

**當日**：
- 大單量提醒 tier（依成交量）：**小型/低量 15/30**、**中型 50/99**、**中大 199**、**權值 499**（手機震動 = 炸板）
- 觸價單 **漲停價 -2~4 tick** 先獲利了結

**隔日 SOP**：
- 開高 ≥ +2.5% 較安全（開高不足 → 賣壓）
- 開高後**殺破平盤價** → 先出觀望
- **開低** → 觸發**開低脫逃 SOP**（下）
- 前一日鎖漲停 → 隔日設**低於收盤價分批觸價**（除非獲利拉開走戰法一 or 飆股守 5 日）
- **盤後籌碼隔日沖多** → 更謹慎（隔日沖守紀律）

**炸板後 SOP（覆盤補）**：
1. 不緊張 → **看 2m 戰法一**
2. **2m 戰法一守住** → **90%+ 會再鎖回**
3. 2m 戰法一破 + 快速站回 → 當日仍強勢
4. 2m 戰法一破 + 未站回 → 不強勢、可退場

**前日漲停族群開低脫逃 SOP（覆盤補）**：
1. 前提：整族群多檔漲停、今日開低 + 2m 10EMA 乖離大
2. 判斷：**不是**持續大單灌跌停 → 主力/集體共識自救
3. 步驟：
   - 2m 乖離過大反彈 → **不跟嗨**
   - **2m 60EMA**（接近平盤 = 昨日收盤）過不去 → **先脫身**（吃到接近昨日漲停獲利）
   - 脫身後再看是否只是回測 15m 趨勢戰法一 / 小時 K 戰法一
4. 交叉檢查：**底部紅三兵失敗**（見 `frank_bottom_3_soldiers`）→ 直接觸發此 SOP

### `frank_hot_stock_hold_5ma`（飆股守 5 日 + 觸價分批）

**raw/06 + raw/11**

- **飆股守 5 日**（收盤破 5 日先出、投信持股可分批留守 10 日、前提獲利拉開）
- **破 5 日又站回** → 再買回（5 日附近進出損失小）
- **狂飆型分批觸價設定**（每天在布林頂之外鎖漲停）：
  1. 鎖漲停 → 隔天鎖漲停戰法；否則設**戰法一破 5m 60EMA 下幾 tick** 分批出
  2. **布林頂價位 -幾 tick** 出一點
  3. **(當日 5 日線價 + 當日股價) / 2** 出一點
  4. **破前一日紅 K 一半** 出一點

### `frank_hot_stock_sideways`（飆股橫向戰法）

**raw/09**

**候選條件**（尚不進場、只列候選）：
1. 破飆股守 5 日、5 日均線開始走平
2. **走平判定**：(a) 視覺橫向 OR (b) 破戰法後每天 5MA 下降次數**不連續超過 3 天**
3. **第一根收盤破 5 日 K 的低點**後續**不能再有 K 收盤跌破**（底不再破低）

**進場**：突破**橫盤平台區高緣**（表態）。
**加分**：底底高（偏多三角收斂）。
**停損**：**收盤破橫盤最高點**。

**常見錯誤**：
- 破 5 日不砍 → 獲利大回吐、無法進入橫向戰法
- 未突破平台高緣先進場 = 賭

**raw/12**

### `frank_daily_neckline_2step`（日 K 頸線 2 步驟長抱防守）
**Source**: 覆盤 `/articles/1A45BAB3...`

**2 步驟畫頸線**：
1. 個股某壓力位一直突破不了 → 確立壓力
2. 突破後日 K 回測能守住 → **壓力轉支撐** → 畫**頸線**

**用法**：
- **頸線不破 = 不出場**（波段長抱訊號）
- **前提**：**成本必須在頸線之下**（收盤破頸線 + 隔天底底低才出、仍有獲利保護）

### `frank_bottom_3_soldiers`（底部紅三兵形成條件）
**Source**: 覆盤 `/articles/26599ED8...`（老大原話）

- **連 2 日爆量** + **第 3 日要能再過高** → 才算成立
- 第 3 日**未過高、直接開低** → 底部紅三兵失敗 → 觸發 `frank_lock_limit_up_playbook` 開低脫逃 SOP

### `frank_indicator_reset_shakeout`（強勢股假急殺 = 主力修 KD 手法）
**Source**: 覆盤 `/articles/9EF9CB99...`

**手法識別**：
- 前提：**小時 K 戰法一維持慣性上/下**（未破）
- 步驟：
  1. 拉高 → 乖離大 + KD 沖到高檔
  2. 「小時 K」KD 高檔鈍化難維持 → 主力**突然黑 K 急殺**
  3. **快速修正 KD 下來**
  4. 回測 60EMA 附近 → 集體共識介入
  5. **日出型態 + 分歧** → 同方向單再湧入

**反模式警告**：
- 散戶笑「跳水了、主力出貨了」→ 實際是**技術指標修正手法**
- 真主力出貨會**趁漲很嗨時偷偷出**、不會這樣公開急殺
- 砍出的散戶單變成**燃料**、主力補買均價

**與 `frank_reversal_precursors` 差異**：
- 真反轉：K 棒**脫離布林頂**、後續未化解
- 假急殺修 KD：小時 K 戰法一**未破** + 快速修正後日出 + 分歧

## 常犯錯誤黑名單（frank_common_mistakes）

**raw/07** — 每次觸發前自檢：

1. **強勢股急殺跟散戶起舞出貨** → 主力洗盤常急跌急漲、去看戰法一多半 60EMA 附近收腳拉回
2. **戰法一回 60EMA 沒看大戶就衝** → 至少大戶賣超收斂才可進
3. **回 60EMA 沒等分歧就衝** → 等後 K 收超前 K（慣性改變）
4. **左側急跌後首次上穿就衝** → 通常會再橫盤震盪、等 60EMA 上揚 30~45° 回測分歧
5. **10EMA 上漲不敢買、被 10EMA 壓卻抄底** → 順勢
6. **大單一敲爆量就追** → 忘記回測 10EMA、用模擬單訓練
7. **族群起漲不敢買大哥去買小弟 or 大戶賣超中的小弟** → 強者恆強、小弟只跟風

## 通用備註（跨戰法）

- **EMA vs MA**：短分時必用 EMA
- **鳥嘴/分歧**：必須建立在**長均線上揚**（否則只是均線上穿）
- **回檔 10EMA**：極強股回 1m 10EMA、普通強回 5m 10EMA（此時 1m 大概回 60EMA）
- **券資比**：持續上升 = 空軍燃料
- **1m 當沖**：股價位於 10EMA 之上/之下慣性 + KD；市場很嗨遠離 10EMA → 當沖客會出（強股會回 10EMA）；市場喊跳水 → 反而留意戰法一 60EMA 不破 + 分歧

## 心態鐵則

- 做股票是**統計學** → 大賺、小賺、小賠組合 → 長期 99% 贏
- 停損不可恥、跌破策略點先賣、後續站回再買回（損失小）
- 進場前先想損點 → 不要買在離 10EMA 太遠
- 大盤多頭時上述戰法效果好；震盪盤/忽空忽多 → 快進快出觸價、不好留倉屬正常
