# 【週報】不可忘記的城牆概念：爆大量K搭配戰法之使用
URL: https://www.pressplay.cc/project/80B62BC940D0E2C916375E88EED5F2E0/articles/41B1BF181AC3E527AD6CA47FE20FAE77

## 觀念：爆量 K = 城牆
- **過爆量高點** = 城牆穩住不垮 → 加分
- **破爆量低點** = 城牆垮 → 要小心

## 爆量後續動態
- 爆量發生後**量沒繼續帶上** → 易短線震盪
- 走勢未確立前（過高 or 破低）→ **多空小兵打架**、極短線 or 空手觀望
- 短線遇高點不過高 + 遇低點不破低
- **表態確立**：突破/跌破後**連續 2 根 K 走同方向**

## 與戰法一組合（分數判斷）
做多得 2 分條件（越多越好）：
1. 股價**符合戰法一**（10EMA 上穿 60EMA + 大戶買超）
2. **爆量 K 高點過**
3. 後續 K **頭頭高**確立方向

任一條件缺 → 分數沒全拿 → 斟酌風險

## 反例（實戰）
爆量低點破 → 戰法一被 10EMA 壓 → 即使又爆量、60EMA 撞不過去 + 爆量低點續破 = 下跌走勢確立。
