# 【新手上路】快打開籌碼K看看這兩個設定
URL: https://www.pressplay.cc/project/80B62BC940D0E2C916375E88EED5F2E0/articles/EE34051E89BAAD7E8201814E272E85D9

## 設定 1：三關價
- 公式產出的個股**支撐/壓力**點位（顯示為虛線）
- 不一定 3 條都出現（除非振幅大）
- **開盤開在上關之上 + 大戶買超** → 常直接衝漲停
- **撞上關過不去** → 常形成賣壓

## 設定 2：EMA 均線
- 反應比 MA 敏銳、更貼近當日股價
- **MA 短線還沒交叉長線但個股已發動** → 看 EMA 常常早已交叉
- **股價跌破 MA 均線** → 看 EMA 是否還沒跌破、可用 EMA 進出判斷
