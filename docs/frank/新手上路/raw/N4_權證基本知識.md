# 【新手上路】權證基本知識實際買賣注意要點
URL: https://www.pressplay.cc/project/80B62BC940D0E2C916375E88EED5F2E0/articles/AB0F4C0D86FA525C33B143AC5EAB2F1C

## 1. 到期月份判讀
權證名 `3C購` → 第 1 碼=年、第 2 碼=月（10=A、11=B、12=C）
- 例：`3C購` = 113 年 12 月到期認購權證（實際日期查權證資料）

## 2. 在外流通看有無投資人進場
權證大數據分析例：「050746 臺股指凱基32購23 當前價格：0.13 交易量：3220 總發行：4000 在外流通：564」
- 在外流通 = 投資人（散戶+大戶）從自營商手中買入的張數
- 全賣出上限 = 564 張
- 今日交易 3220 張 > 564 → 有投資人**新進場**（買入）

## 3. 芭樂單風險
- 在外流通張數快等於發行張數 = 該檔快被買滿
- 自營商委賣掛很低量（如 10 張 10 張）
- **現股已漲停** → 自營商有權不掛價 → 有人掛**芭樂價**（溢價等阿呆散戶）
- SOP：這時買賣**必用「權證計算機」算合理價**

## 4. 市價買賣風險
- 現股波動大 → 自營商有權先不出價 → 場上只剩芭樂單
- **市價下單** → 剛好買/賣到芭樂價
- **避免市價**、用限價

## 5. 實質槓桿必看
- 例 050746：32購長期到期 + 低價、看似安全 → 實質槓桿高達 27 倍
  - 因為履約價 19,000 價外太多 + 隱波低
- 大戶狂敲 ≠ 穩贏
- 高槓桿必設**能承受下跌的停損點**
