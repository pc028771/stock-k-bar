## 大盤 vs OTC
- **大盤**：加權指數，權重最重 = 台積電 + 其他 0050 權值股（鴻海、聯發科、台達電、聯電）
- **OTC**：櫃買指數（中小型）
- 資金輪漲：大盤高但小型不漲 or 中小飆但台積不飆
- 多頭常態：台積電領頭撐指數 → 中小型補漲

## 多空 vs 權證
- 做多 / 認購權證 = 看漲
- 做空 / 認售權證 = 看跌
- 現股漲越多 → 認購獲利越大（先不考慮隱波、時間價值）

## 當沖 / 資券
- **當沖**：當天買賣同一檔
- **現沖**：現股當天買賣
- **資券當沖**：融資買 + 融券賣
- 盤中資券當沖、盤後營業員會幫改成現沖（**現股當沖有稅金減免**）
- 交易別調整可請營業員盤中改（如太大金額改融資，記得融資有利息）
- **融資不限額、融券有限額**（放空過多可能無券可借）

## 籌碼
- 四大主體：外資、投信、自營商、主力（本土券商分點）
- **Frank 只看投信 + 主力**（外資多假外資、自營商避險買現股後易反手）
- 主力觀察：
  1. 本土分點**低檔持續買 + 高檔開始出脫**
  2. 該股**股務單位** = 常勝分點

## 均線 MA
- **日 K MA**：5MA / 10MA（投信買超守）/ 20MA（月線）/ 60MA（**季線 = 生命線 = 多空分水嶺**）/ 120MA（半年線）/ 240MA（年線）
- 分時 K 一樣邏輯：1m 5MA = 5 分鐘均價、週 K 5MA = 5 週均價

## KD
- K 交叉 > D = 金叉、K 交叉 < D = 死叉
- 一般標線 20 / 80 判斷高低檔

### Frank 反向 KD 觀點（獨特）
- **20 以下低檔金叉**：常是**反彈逃命波**、要賣出（除非直接拉一根漲停過 20）
- **80 以上高檔死叉**（飆股/強勢股）：常是**拉回上車點**、要買入（除非直接一根跌停破 70）
- 這是個人經驗、依自己常勝法為準

## KD 背離
- **高檔背離**：股價創新高 + KD 不創高 → 準備回調
- **低檔背離**：股價創新低 + KD 不創低 → 準備上升
- Frank 用最多在 **5m KD 背離做極短線當沖**

## 爆量 K
- 找近期最大量 K 棒
- **突破爆量 K 高點** → 壓力轉支撐
- **跌破爆量 K 低點** → 支撐轉壓力
- 原理：套牢/獲利者集體行為

## 趨勢設點
- **上漲趨勢**：設撐不設壓（讓利潤跑）
- **下跌趨勢**：設壓不設撐
