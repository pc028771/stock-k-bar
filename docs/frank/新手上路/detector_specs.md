## `frank_basic_glossary`（術語 & 觀念）

**raw/N5**

### 市場
- **大盤**：加權指數（台積電權重最重 + 0050 權值股）
- **OTC**：櫃買（中小型）
- 資金輪漲：大盤 vs OTC 常互補；多頭常態 = 台積領頭、中小型補漲

### 交易別
- **現沖 = 現股當天買賣**（有稅金減免）
- **資券當沖 = 融資買 + 融券賣**（盤後營業員會幫改成現沖、沒改要告知）
- 交易別可請營業員盤中調（如太大金額改融資、注意融資有利息）
- **融資不限額、融券有限額**

### 籌碼
**Frank 只看**：投信 + 主力（本土券商分點）

**外資排除理由**：太多假外資
**自營商警告**：狂大買常是權證避險買現股 → 股價一跌就會出脫避險
**主力觀察**：
1. 本土分點低檔持續買 + 高檔出脫
2. 該股**股務單位** = 常常是勝利分點

### 均線
| MA | 意義 |
|---|---|
| 5MA | 飆股守 |
| 10MA | 投信買超守 |
| 20MA | 月線 |
| 60MA | **季線 = 生命線 = 多空分水嶺** |
| 120MA | 半年線 |
| 240MA | 年線 |

分時 K 邏輯相同：1m 5MA = 5 分鐘均價、週 K 5MA = 5 週均價、月 K 5MA = 5 個月。

### KD（Frank 反向獨門觀點）
- **20 以下低檔金叉** = 常是**反彈逃命波要賣**（除非直接漲停過 20）
- **80 以上高檔死叉**（飆股/強勢股）= 常是**拉回上車點要買**（除非跌停破 70）

### KD 背離
- **高檔背離**：股價創高 + KD 不創高 → 準備回調
- **低檔背離**：股價創低 + KD 不創低 → 準備上升
- Frank 用最多：**5m KD 背離做極短線當沖**

### 趨勢設點
- **上漲**：設撐不設壓
- **下跌**：設壓不設撐

## `frank_wall_of_volume`（爆量 K = 城牆）

**raw/N1**

- **過爆量 K 高點** = 城牆穩住不垮 → 加分（壓力轉支撐）
- **破爆量 K 低點** = 城牆垮 → 小心（支撐轉壓力）

### 爆量後續判讀
- 爆量後**量沒續帶** → 短線震盪、多空小兵打架、極短線 or 空手觀望
- **表態確立** = 突破/跌破後**連續 2 根 K 走同方向**

### 戰法一 + 爆量分數制（做多）
1. 符合戰法一（10EMA 上穿 60EMA + 大戶買超）
2. 爆量 K 高點過
3. 後續 K 頭頭高

分數越全越好，缺項要斟酌風險。

**反例**：爆量低點破 → 戰法一被 10EMA 壓 → 即使又爆量、60EMA 撞不過去 + 爆量低點續破 = 下跌走勢確立

## `frank_warrant_essentials`（權證買賣 5 大注意點）

**raw/N4**

### 1. 到期月份判讀
權證名前兩碼：年 + 月（A=10、B=11、C=12）
- 例：`3C購` = 民國 113 年 12 月到期認購

### 2. 用大數據判斷有無投資人進場
- 在外流通張數 = 投資人（散戶+大戶）從自營商買入
- 今日交易 > 在外流通 → 有**新進場**（買）
- 例：交易 3220 張 vs 在外流通 564 張 → 全賣出上限 564 → 明顯新買方

### 3. 芭樂單風險
- 在外流通 ≈ 發行張數（快被買滿）
- 自營商委賣掛極低量（10 張 10 張）
- **現股漲停 + 自營商有權不掛價** → 場上剩芭樂價（溢價）
- **必用「權證計算機」算合理價**

### 4. 避免市價
- 現股波動大 → 自營商可先不出價 → 場上剩芭樂單
- **市價下單 = 剛好買/賣到芭樂價**
- 一律限價

### 5. 實質槓桿必看
- 例：32購長期到期 + 低價、看似安全 → 實質槓桿 27 倍（履約價價外太多 + 隱波低）
- 大戶狂敲 ≠ 穩贏
- 高槓桿必設**可承受下跌的停損**
