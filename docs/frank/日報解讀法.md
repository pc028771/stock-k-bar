### 五條解讀規則

1. **新聞筆記「首見的新名字」= 他的 watch 入池、1~4 天內可能動手**
   - 智邦 7/2 首見 → 7/6 下殺時買（lead time 4 天）
   - 新纖 7/3 首見（同時入處置 5 日名單）→ 當天尾盤買
   - 雙鍵 7/2 首見 → 7/6 line 提及持續觀察
2. **同名字連續出現多天 = 主題延續 or 他持倉中**
   - 中纖 7/1→7/2→7/3→7/6 連四篇 = 化工/AI 題材主軸
   - 亞泰 7/3→7/6 重複 = 已持倉的續抱背書（**不是新訊號**）
3. **資金族群榜 = 他的族群雷達、連續上榜的族群他會回頭接**
   - 被動 7/1、7/3 連上榜 → 7/6 接回禾伸堂
   - IC 封測 7/3、7/6 連上榜（與尼克封測核心倉 thesis 共振）
4. **處置 5 日名單 = 飆股候選池**（W12 選股法原料）
   - 新纖上榜日 = 買進日的直接案例
   - 反向用法：持有的股「即將進處置」= 流動性風險預警（順德 7/6 入列）
5. **使用資金 % = 他的水位儀表、看方向不看絕對值**
   - 6/29 剩 1 檔 → 7/1 80% → 7/3 滿倉 → 7/6 90%
   - 他在洗盤末端**一週內從空手重建到滿倉** — 與尼克「準備咬」完全同步、兩位老師用不同語言講同一個盤

### 每日 5 分鐘讀法（checklist）

1. 標題掃一眼（N 檔漲停 = 他的組合狀態）
2. 外資台指空單：**方向**（連續回補 = 空方鬆手）
3. 新聞筆記：圈出**首見新名字** → 丟進 watch、查戰法位階
4. 資金族群：跟昨天比、**新上榜/連續上榜**的族群
5. 處置 5 日名單 ∩ 自己的 watch/持倉（機會 + 風險兩面）
6. 使用資金 %：比昨天增或減

## 三、與尼克週報的分工

| | Frank 日報 | 尼克週報/課 |
|---|---|---|
| 頻率 | 每日盤後 | 每週 + 每日課 |
| 視角 | 資金流當下在哪（戰術）| 族群敘事與位階（戰略）|
| 用法 | 找「正在發生」的名字 | 決定「該不該參與、參與多大」 |
| 交叉 | 兩邊同時出現的族群/標的 = 最高信度（例：封測、被動）| |
