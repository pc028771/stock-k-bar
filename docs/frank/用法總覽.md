## 🎯 Step 1：選你的時間軸（決定主戰法）

| 你有多少時間 | 主戰法 | Detector |
|---|---|---|
| **盤中盯 1~2m K**（當沖/極短線）| 1m/2m 戰法一 | `frank_1m_2m_scalping` |
| **盤中偶爾看**（短線~短波、幾天）| 5m 戰法一 | `frank_1_short_ema_cross` |
| **每天看一眼**（波段、幾週）| 日 K 布林戰法二 | `frank_2_bollinger_upper_band` |
| **上班族一週看一次**（長波、幾月）| 週 K 戰法二延伸 | `frank_2_weekly_extended` |
| **懶人一週看一眼**（長期）| 月 K 戰法三 | `frank_3_monthly_kd_macd` |

## ⏰ Step 2：每日時段 SOP checklist

### 📋 盤前功課（前晚 or 早上 8:30~8:55）
`raw/16` 官方 SOP：
- [ ] 審視庫存持股 → 有沒有日 K 反轉向下
- [ ] 三大法人：投信 / 主力（本土分點）**賣超 3 天+ 剔除**
- [ ] 籌碼：常勝分點 / 主力分點是否開始賣 → `frank_broker_lookup`
- [ ] 讀盤後文章看大盤 + 新聞
- [ ] 均線扣抵蹺蹺板判**明日方向** → `frank_ma_kokouyaka_seesaw`
- [ ] **設觸價單**：漲停個股必設、獲利拉開的隔天沒破 5 均 OK
- [ ] **選股清單**：週轉率 Top 15 + 5 天後進處置 → `frank_hot_stock_scan_daily`
- [ ] 概念族群龍頭排序 → `frank_theme_stock_scan`

### 🌅 開盤 09:00~09:15（**只觀察、不追**）
- [ ] 看第 1 根 5m K 過不過前日高 → `frank_daily_open_5m_key_level`
- [ ] 自選股：大戶賣超剔除、只看買超
- [ ] 開盤 +7% 以上緩漲/緩跌警示 → `frank_slow_up_down`
- [ ] 撞上關過不去 = 隔日沖丟貨警訊
- [ ] 開盤 5 分鐘漲幅 > 5% = **skip 整檔**（CLAUDE.md 紀律鐵三）
- [ ] 前 10 分鐘**不切入**

### 🎯 盤中 09:15~12:59（監控 + 條件進場）
**新進場**：
- [ ] 找 5m 10EMA + 60EMA **多頭排列**
- [ ] 進場觸發：主戰法訊號成立 + `frank_wall_of_volume` 爆量城牆過高
- [ ] 五檔戰法確認無假掛單 → `frank_5tick_fake_order`
- [ ] KD 位置檢查（`frank_intraday_entry_5m_kd`）：KD 高檔 → **緩緩、別追**
- [ ] 保守進場 4 型（`frank_conservative_low_loss_setups`）：找損最小的
- [ ] **不熟就用模擬單試單** → `frank_paper_trade_test`

**已持有**：
- [ ] 主單守飆股 5 日 / 投信 10 日 → `frank_daily_retracement_5ma_10ma`
- [ ] 加碼守 5m 戰法一 → `frank_add_position_defense`
- [ ] 頸線不破不出場 → `frank_daily_neckline_2step`

### 🌆 尾盤 13:00~13:25（**進場黃金時段**）
- [ ] CLAUDE.md 鐵則：**尾盤才進場**、Closing 3~4/5 才買
- [ ] 分批進場 SOP（見主 repo memory）
- [ ] **鎖漲停個股**：設大單告警 15/30/50/99/199/499 → `frank_lock_limit_up_playbook`
- [ ] 隔日觸價：漲停個股 -2~4 tick 分批獲利了結

### 📊 盤後（15:00~）
- [ ] 檢視今日交易日誌
- [ ] 更新明日觀察清單
- [ ] 週 5/週 K 收盤後檢查戰法二/三

## 🚨 Step 3：情境對照表（遇到 X 用哪個 detector）

| 情境 | 用什麼 | 動作 |
|---|---|---|
| **持股噴、想加碼** | `frank_add_position_defense` | 想成空手時會進的點、加碼 ≤ 主單 |
| **持股跌、要不要砍** | `frank_wall_of_volume` + 主戰法檢查 | 城牆不破 + 戰法一未破 = 抱、都破 = 出 |
| **大盤/美股崩** | `frank_us_stock_dump_next_day_sop` | 15m 城牆 K 低不破 = 別急砍；破了 = 保留資金等新爆量 |
| **鎖漲停** | `frank_lock_limit_up_playbook` | 設大單告警 + 隔日 SOP + 炸板看 2m 戰法一 |
| **炸板** | `frank_lock_limit_up_playbook`（炸板 SOP）| 2m 戰法一守 = 90% 會鎖回 |
| **開盤緩漲/緩跌** | `frank_slow_up_down` | 冷靜、等回測 10EMA/60EMA 再承接 |
| **前日整族群漲停、今日開低** | `frank_lock_limit_up_playbook`（脫逃 SOP）+ `frank_bottom_3_soldiers` | 2m 60EMA 過不去先脫身 |
| **飆股連漲 3 天** | `frank_hot_stock_3_5_rule` | 第 3 / 5 天開盤看 5m 關鍵 K 是否守 |
| **強勢股急殺很嚇人** | `frank_indicator_reset_shakeout` | 小時 K 戰法一未破 + 日出分歧 = 假急殺、別砍 |
| **持股噴到嚇死自己** | `frank_daily_neckline_2step` + `frank_hot_stock_habit_reversal` | 頸線 / 5MA / K 脫離布林頂 三選一守 |
| **飆股破 5 日了** | `frank_hot_stock_sideways` | 走橫向、突破平台高再進 |
| **上漲乖離大、想停利部分** | `frank_add_position_defense` 分批表 | 8~14% 破前日 K 低、15%+ 破紅 K 一半 |
| **當沖被巴、想抱又不敢** | `frank_15m_ema_trend_ride` | 15m 兩條線中間戰法 |
| **多空交戰、五檔跳動** | `frank_5tick_fake_order` + `frank_paper_trade_test` | 反著看 + 模擬試單 |
| **想跟大戶買權證** | `frank_warrant_big_player_signal` + `frank_lottery_warrant` | 在外流通低突爆量 = 大戶進；≤0.2 元長天期買樂透 |
| **台指多單獲利+150 遇震盪** | `frank_taifex_hedge_lock` | 15m 高背+日落 → 對鎖空單 |
| **抱單開始緊張** | 看 `frank_common_mistakes` 對照 | 反思是否落入 7 大錯誤 |

## 🔴 Step 4：紀律鐵則（不管用哪個 detector 都要遵守）

**Frank 官方**：
- 停損不可恥、跌破策略點先賣、站回再買回
- 大賺+小賺+小賠組合、不容許大賠
- 進場前想損點：不買離 10EMA 太遠
- 大盤多頭時效果好、震盪盤觸價快進快出屬正常

**專案 CLAUDE.md 疊加鐵則**（本 repo user 自訂）：
- ⛔ 漲停隔日跳空 ≥ +3% 不推
- ⛔ 前 5 分鐘漲幅 > 5% 一票否決
- ⛔ 09:00~12:59 只觀察、13:00 後才進
- ⛔ 距 MA10 > +10% 過熱 + 老師明示才進
- ⛔ 課程外條件（非 Frank 明說）禁止進 detector 主目錄、只能放 extras/
- ⛔ 個股 > $600 用零股 200~500

## 🧠 一句話總結

**選 1 個時間軸 → 用那個時間軸的主戰法 → 其他 detector 只在觸發情境時當補丁用、不要全部同時看**。

看太多 detector 反而會癱瘓。90% 交易只用**主戰法 + 爆量城牆 + 5m KD** 就夠了。
