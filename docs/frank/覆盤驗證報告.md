## 樣本 1：日 K 頸線 2 步驟 🆕

**Source**: `/articles/1A45BAB3...`

**規則**：
1. 個股某壓力位一直突破不了 → 確立壓力
2. 突破後日 K 回測能守住 → **壓力轉支撐** → 畫**頸線**
3. **頸線不破就不出場**
4. 前提：**成本在頸線之下**（收盤破頸線 + 隔天底底低才出、仍有獲利）

**現有 spec 覆蓋**：❌ 無 → **新增 `frank_daily_neckline_2step`**

## 樣本 2：鎖漲停炸板 2m 戰法一 ⚠️

**Source**: `/articles/BB9B1116...`

**規則**：
- 大單告警 tier：**15 / 30 / 50 / 99** 張（依當日成交量）
- 炸板後**看 2m 戰法一**：守 → **90%+ 會鎖回**
- 不守站回 → 仍當日強勢

**現有 spec 覆蓋**：⚠️ `frank_lock_limit_up_playbook`（統整戰法 + W17）
- 已有：大單告警 30/50/99/199/499
- 缺：**15 / 30 較小 tier**、**炸板後 2m 戰法一觀察 SOP**
→ **補強** `frank_lock_limit_up_playbook`

## 樣本 3：前日漲停族群開低 → 主力自救脫逃 ⚠️🆕

**Source**: `/articles/26599ED8...`

**規則**：
- **底部紅三兵**：連續 2 日爆量、**第 3 日要能再過高** 才形成
- 一早開低 + 離 2m 10EMA 乖離大 + 未持續大單灌跌停 → **主力/集體共識自救**
- 脫逃 SOP：
  1. 2m 乖離過大反彈、**不跟嗨**
  2. **2m 60EMA**（接近平盤價 = 昨日收盤）過不去 → **先脫身**
- 脫身後再看是否只是回測 15m 趨勢戰法一 / 小時 K 戰法一

**現有 spec 覆蓋**：
- ⚠️ `frank_lock_limit_up_playbook` 說「隔日開低直接離場」→ 太粗、覆盤補**細緻脫逃 SOP**
- ❌ 「底部紅三兵」 → NEW
→ **新增 `frank_bottom_3_soldiers`** + **補強** lock playbook 脫逃步驟

## 樣本 5：強勢股「快速修正技術指標」手法 🆕

**Source**: `/articles/9EF9CB99...`

**規則**：
- 前提：小時 K 戰法一持續慣性上/下
- 主力手法：**拉高 → 乖離大 + KD 沖高** → **突然黑 K 急殺** → **快速修正 KD 下來**
- 回測 60EMA 附近 → 集體共識介入
- **日出型態 + 分歧** → 同方向單再湧入
- 反模式：散戶笑「跳水了、出貨了」→ 實際是**技術指標修正手法**、砍出後**變燃料**

**現有 spec 覆蓋**：⚠️ 只有零散提及（W22 反轉前兆有反例）
- 缺**完整的「假急殺 = 修正 KD」手法識別 SOP**
→ **新增 `frank_indicator_reset_shakeout`**

## 樣本 6：垂直拉抬 + 上關戰法 + 爆量城牆 ✅

**Source**: `/articles/2918BB0D...`

**規則**：
- 沿 2m 戰法一混 → 分歧後出量拉抬
- 遇**整數大關 + 上關**（當日壓力最大）
- **過上關 + 回測守住** → 有機會漲停
- **過上關但未守 + 2m 戰法一乖離最大處爆量城牆破** → 集體共識獲利了結
- 隔天日 K 爆量低點觀察、守住 → 有機會再挑戰

**現有 spec 覆蓋**：✅ 組合現有 spec
- `frank_wall_of_volume`
- `frank_kchart_essential_setup`（三關價、含上關）
- `frank_1m_2m_scalping`
