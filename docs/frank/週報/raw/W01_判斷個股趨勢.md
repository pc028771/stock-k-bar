# 【週報】學會判斷個股（大盤也通用）趨勢
URL: /articles/4F95FEB16B739A47540FB2A345C9A88A

## 核心：均價線斜率
- **日均線斜率為負**（左上→右下）= 當日空方趨勢
- **日均線斜率為正**（左下→右上）= 當日多方趨勢

## 空方 SOP（配合三關）
- 開盤破**中關**、反彈中關過不去（均線在那 → 雙重壓力）
- 下跌到**下關**遇 KD 低檔正常反彈
- 反彈上去撞均線又過不去 → 抓每次反彈 + KD 高檔做空

## 多方 SOP（配合三關）
- 開盤過**中關** → 一路拉到上關
- 突破上關拉高做回測（此時 KD 高檔）
- 遇**上關 + 日均線 + KD 低檔** = 三重支撐 → 反彈續攻
