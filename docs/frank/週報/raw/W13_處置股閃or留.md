# 【週報】處置股 — 閃人 or 留倉
URL: /articles/9CFA1D511AACD293CA31EA08D4888BDC

## 兩個判斷條件（同時符合 → 可留倉）
1. **入處置前 1~2 天**、日 K 出現**爆大量**
2. 該股仍**守著小時 K 戰法一**

## 原理
- 個股要入處置 + 仍守長趨勢戰法 + 爆大量 → **絕大買盤在處置前偏向進駐**
- 敢在處置前大量進場 = 主力
- 尤其**20 分處置分盤**：
  - 不可融資、融券
  - 買入需**全額交割**
  - 一天量非常少
  - **主力處置前爆量進場後、處置期間無法出貨**（出貨要氣氛嗨 + 買單夠足）
- 有此勇氣進場的分點 → 後續處置中創波段高 or 處置結束又拉高機率非常大

## 案例
處置前爆量 + 持續守小時 K 戰法一 → 處置期間拉高 + 後續創新高
