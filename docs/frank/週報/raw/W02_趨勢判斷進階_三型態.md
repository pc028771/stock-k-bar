# 【週報】趨勢判斷進階 — 三型態
URL: /articles/31B483AF796822AF7C0B33F3192FC16B

## 三種型態
1. **常態型（碗公）**：壓著打下去 → 橫向 → 沿均線上攻
2. **上攻型（向上 N）**：沿均線上攻 → 橫向 → 沿均線上攻
3. **下跌型（向下 N）**：壓著打下去 → 橫向 → 壓著打下去

## 極短線（1m / 5m）用 10EMA + 60EMA
- 空方：被 10EMA 壓著打
- 低點不再破低 → 觀察箱型（突破 10EMA、遇 60EMA 又下）
- 60EMA 開始接近 10EMA 甚至糾結 → 等**大量突破 60EMA 表態**
- 10EMA 上穿 60EMA（戰法一）→ 沿 10EMA 上攻

## 日 K 格局用 5MA + 20MA
- 空方：被 5MA 壓著打
- 低點不再破低 → 箱型（突破 5MA、遇 20MA 又下）
- 20MA 靠近 5MA 糾結 → 等**大量突破 20MA 表態**
- 5MA 上穿 20MA → 沿 5MA 上攻（**飆股守 5 日格局**）

## 反向套用
- 空方橫向後又空方走勢：型態 3
- 多方橫向後又多方走勢：型態 2

## 案例
- 極短線：華城 1m — 10EMA 壓 → 箱型 → 突破 60EMA + 戰法一 → 沿 10EMA
- 日 K：宏碁 — 5MA 壓 → 箱型 → 突破 20MA + 5MA 上穿 20MA → 沿 5MA
