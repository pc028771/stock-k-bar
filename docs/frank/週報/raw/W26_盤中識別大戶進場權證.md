# 【週報】盤中識別大戶進場之權證
URL: /articles/C891FA35B8574A89FD11D78E4B913899

## 基礎
- 權證 = 自營商 vs 投資人（散戶+大戶）交易
- 每檔權證有發行量（例：5000 張）
- 投資人買 1 張 → 在外流通數 +1

## 大戶進場訊號
- **在外流通數 ≤ 500** 突然**爆大量 3000~4000+ 張** = 大戶進場（散戶不會有這麼多錢）

## 案例（圖一）
- 在外流通 < 500
- **8/31 大量 3000+ 張**
- **9/1 再補 1000+ 張** → 在外流通 4970 張（幾乎買滿發行量）
- 隨後一段漲幅
- **10/5 又爆大量、但此時在外流通已滿** → 投資人**退場**（因為無法再流入 → 只能減）

## 結論
只要掌握「在外流通低 → 突然爆大量」訊號 → 跟隨權證大戶。分析工具與細節在訂閱者 line 群。
