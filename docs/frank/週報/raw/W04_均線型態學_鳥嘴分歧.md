# 【週報】最好用的均線型態學 - 1（鳥嘴 vs 分歧）
URL: /articles/3514ADD8F842AF2943042D9ED51BFB01

## 兩大要點（以日 K 為例）

### 鳥嘴
- 短均 **5MA 上穿「上揚」的長均 20MA**（中軌）
- 對應戰法一：短均上穿長均

### 分歧
- 短均 5MA 原本向下、但**「上揚」的長均 20MA 沒碰到就又鉤上去**
- 對應戰法二：回後買上漲

## 差異（動能）
- **鳥嘴** = 形成後可能嘴巴又閉起來（不穩定）
- **分歧** = 更引起**程式單注意**（股價上漲後回測、受買盤青睞又上漲 → 集體共識強）

## 通用性
不侷限日 K：
- 鳥嘴 ≈ 戰法一短均上穿長均
- 分歧 ≈ 戰法一股價回測 60EMA 後又上漲

## 前提（重要！）
兩者都必須建立在**長均線上揚**才有效（否則只是均線上穿）。

## 空方反向
兩型態反過來即為空方訊號。
