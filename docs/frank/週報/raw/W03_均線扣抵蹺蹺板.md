# 【週報】均線扣抵與均線走勢推測理論
URL: /articles/E37E074D53EA19D14F69B7E774F8BC6C

## 蹺蹺板圖像法（Frank 獨創）
- 扣抵公式不用記
- APP 用 60MA 角度會標示**今日股價往前第 60 天位置**的小三角形
- **拿尺**：三角形股價 + 現在股價連線 = 蹺蹺板

## 三種走勢
| 蹺蹺板 | 意義 |
|---|---|
| **左上→右下** | 下降力道強、目前走勢空頭 |
| **接近平行** | 區間震盪 |
| **左下→右上** | 上攻力道強、目前走勢多頭 |

## 案例延伸
- **左上→右下**：扣抵壓力高、KD 到高檔即遇壓被出貨、無法高檔震盪 → 均線下彎原理
- **左下→右上**：扣抵壓力低、KD 到低檔即有買盤、不會低檔震盪 → 均線上揚原理
- **接近平行**：均線持平原理

## 平行時的股價位置判讀
- 股價在**均線之上** → 通常是下跌後低檔橫盤整理、醞釀翹上去發動攻擊
- 股價在**均線之下** → 通常是上漲後高檔橫盤整理、醞釀翹下去出貨

## 推測用途
看**扣抵那天往後幾天當時的走勢** → 推測該股接下來扣高 or 扣低 → 影響未來均線走勢。
