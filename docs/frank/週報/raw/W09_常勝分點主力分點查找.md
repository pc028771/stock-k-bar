## 查找 SOP
1. 工具：籌碼 K / XQ 付費 → 個股籌碼功能；沒付費 → `histock.tw/stock/branch.aspx?no=股票代號&day=120`
2. **120 天統計**、扣除排除清單
3. 篩出：**買超相對大量 + 均價不是相對高**（最好買均價最低）
4. **點入分點確認買賣慣性**：不能是「一天買一天賣」
5. 最好是**集中某區段大買、沒什麼賣**
6. 得出 ~7 成個股常勝/主力分點

## 用法
- 看該分點最近買賣狀況 + 買超均價 → 輔佐進出場
- 短波/長波才重籌碼；短線用戰法一為主

## 適用範圍
- **不適用大股本大權值**（外資主導）
- **中小型個股較好查**
