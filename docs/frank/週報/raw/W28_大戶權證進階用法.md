# 【週報】大戶權證進階用法
URL: /articles/18D341C72E26CE49707DC396E01BA615

## 高勝率參考方式

1. **固定金額而非固定張數**（均注概念）
   - 每檔固定買 5000、1 萬
   - 避免獲利大買少張、虧損大買多張

2. **等隔日再買**（隔天現股仍符合戰法）
   - 隔天續漲 → 大戶方向對
   - 隔天跌回測有撐進場（大戶還沒出）→ **買比大戶還低價**
   - 大戶套牢會自己點火作價逃命 → 大戶小虧/平出、你賺錢出

3. **大數據告訊：大戶進場加權權證 or 台積權證** → 後續勝率高

4. **高槓權證**：大戶通常先知有內褲 X
   - 也會有韭菜時 → 高槓建議只買樂透、切忌重壓
   - 除非自己知道「內褲 X」是啥
