# 【週報】券資比 — 短期強勢股趨勢延續判斷
URL: /articles/033E79AF6F42FF10BA21C45B3BCE8551

## 觀念
- 三大法人不得信用交易 → 融資/融券是**散戶指標**
- 主力也用融資 → 融資判斷不準
  - 飆股上漲 + 融資增加 = 聰明融資（主力 + 散戶）
  - 下跌 + 融資增加 = **笨蛋融資**（確立散戶）

## 券資比公式
**券資比 = 融券 / 融資**（融券比例 > 融資 → 券資比上升）

## 適用範圍
- **短期強勢個股**上漲趨勢延續判斷
- **不適用**區間震盪盤

## 原理（主力反向操作）
- 飆漲時散戶覺得漲夠了要空 → 融券增加 → **券資比上升**
- 主力見融券增加 → 誘散戶做空 → 找時機強拉逼回補 → **嘎空燃料**
- 券資比**下降**（融資 > 融券）→ 主力想讓散戶融資斷頭 → 股價回跌

## SOP
- 飆股券資比一路攀升 → 上漲延續、空單變燃料
- 飆股券資比**開始下降** → 更加小心（可能回檔）

## 注意
- 不是絕對、單日下降隔天可能回升 → 只做**參考**
