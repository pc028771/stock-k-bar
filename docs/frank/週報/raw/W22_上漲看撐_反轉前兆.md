# 【週報】上漲回升看撐 & 反轉前兆

## 加權指數戰法二運用（觀察上漲回升）
- 布林 = 一條 5MA + 一條 20MA
- 5MA 下穿 20MA = 破戰法二
- 破戰法二後首次挑戰站回 20MA 但**上穿不了 → 反向分歧**
- 5MA 終於上穿 20MA → 大盤確立進入回升反彈

## 高階回升位階觀察 4 要點
1. **均線扣抵蹺蹺板**：5MA 上揚 + 20MA 即將扣抵下、觀察兩線持續上揚
2. **看撐不預設壓力**：目前撐 = 5MA、觀察指數沿 5MA 前進；獲利大者最低限度守 20MA（再次破戰法二）
3. **KD 80 以上高檔鈍化**：進強勢區、觀察能否高檔鈍化；**日 K KD 破 80 死叉要小心**
4. **看不懂 or 有風險** → 用**台指期鎖單**（對鎖）

## 反轉徵兆（2 分 K 極短線示範、脈絡通用個股/台指）
### 過程
- 前兩波爆大量城牆 → 低守高破 → 上攻、10EMA 一路守
- 第三波兩個爆大量、其中**爆量-2 出現長上影**（大單一直敲、當沖客愛丟）
- 長上影單一 K 可先不急、重點看**下一根需開高走高化解**
- 若下一根**黑 K 直接破爆量低** → 準備反轉心理準備
- 接著短線 10EMA 跌破 → 第三波爆量-1 也破 → **反轉點確立**

### 後續
- 拉回後走橫盤 + 低不破低 → 相當於日 K 飆股整理 2~3 個月
- 觀察**過區間高（再攻）or 破區間低（回升未到）**
