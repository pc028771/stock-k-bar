# 【經典週報】布林通道波段
URL: /articles/4DC1C426A27F60D8A08460BB46058E42

## 觀念
季線是股票生命線；波段等跌破季線太遲 → 用**月線**（= 布林中軌）預判。
除權息前後用**還原 K**。

## 布林三線
- **上軌**：均線標準差計算
- **中軌 = 20MA**（日 K 下 = 月線）
- **下軌**：均線標準差計算

## 關鍵狀態
- **開布林**：橫盤震盪時三線接近平行（震盪小 → 壓縮）；表態 → 開口打開（走上軌/下軌）
- **高檔反轉**：股價打布林頂 + **壓在頂上形成黑 K（尤其連 2 黑）** → 回檔
- **低檔反轉**：股價打布林底 + **壓在底上形成紅 K（尤其連 2 紅）** → 反彈

## 中軌方向決定多空
- **中軌上揚**（月線上揚）→ 股價位於**上軌區間** → **回後買上漲**（撞頂回跌到中軌出現紅 K 買）
- **中軌下彎** → 股價位於**下軌區間** → 撞底反彈到中軌出現黑 K 賣/空

## 簡化 SOP
- 月線上揚 + 股價維持上軌區間 = 強勢
  - 打頂回跌**減碼**、打中軌回漲**加碼**、抱緊
- 月線下彎 + 股價維持下軌區間 = 弱勢
  - 打底反彈**搶反彈**、打中軌回跌**結束搶反彈**
  - 空手觀望或積極者放空

## 橫盤震盪
- 布林頂減碼、布林底加碼來回做
- 加**離股價最近的均線**（如半年線）判斷打腳位置
- 進場即使停損損失小、上去可抓到碰中軌獲利
- 最佳表現：突破橫盤箱型高點、表態開布林
