## 🌟 趨勢判斷（4 篇）

### `frank_daily_average_slope`（均價線斜率判趨勢）
**raw/W01**
- **日均線斜率為負**（左上→右下）= 空方 → 三關反彈搭 KD 高檔做空
- **日均線斜率為正**（左下→右上）= 多方 → 三關支撐搭 KD 低檔加碼

### `frank_trend_three_types`（趨勢慣性三型態）
**raw/W02**
| 型態 | 走勢 |
|---|---|
| 常態型（碗公）| 壓著打 → 橫向 → 沿均線上攻 |
| 上攻型（上 N）| 沿均線上攻 → 橫向 → 沿均線上攻 |
| 下跌型（下 N）| 壓著打 → 橫向 → 壓著打 |

- **極短線** 用 10EMA + 60EMA
- **日 K 格局** 用 5MA + 20MA
- 空方 → 低點不破低 → 箱型 → 長均糾結 → 大量突破長均 + 短均上穿長均 → 沿短均上攻

### `frank_ma_kokouyaka_seesaw`（均線扣抵蹺蹺板）
**raw/W03**（Frank 獨創）
- 三角形位置（60MA 就是往前第 60 天）+ 現在股價**連成一條線**
- 左上→右下 = 空頭、平行 = 震盪、左下→右上 = 多頭
- 解釋均線下彎/持平/上揚原理
- **平行時看股價位置**：
  - 均線之上 = 低檔橫盤醞釀翹上去攻擊
  - 均線之下 = 高檔橫盤醞釀翹下去出貨

### `frank_ma_beak_divergence`（均線型態學：鳥嘴 / 分歧）
**raw/W04**
- **鳥嘴**：短均上穿**上揚**的長均（≈ 戰法一短均上穿長均）→ 可能又閉起
- **分歧**：短均向下、但**上揚**的長均沒碰又鉤上（≈ 戰法一回測 60EMA 又上）→ **程式單愛**
- **前提**：長均必上揚
- 空方反向

## 🎯 進場戰法

### `frank_intraday_entry_5m_kd`（盤中買賣點 5m KD）
**raw/W05**
- 追買前看 5m KD **高檔就先緩緩**（主力賣出常大單連擊誘散戶抬轎）
- 想空前看 5m KD **低檔難吃到肉、隨時反彈**
- SOP：等 KD 下來再買（除非直接鎖漲停）

### `frank_intraday_entry_10ema_60ema_kd`（盤中買賣點 10EMA+60EMA）
**raw/W06**
- 5m + 10EMA + 60EMA + 5m KD
- 進場：10EMA 上穿 60EMA + 5m KD 未向下
- 出場：10EMA 下穿 60EMA + 5m KD 向下

### `frank_bollinger_swing`（布林通道波段）
**raw/W07**
- 三線 = 上軌 + 中軌（20MA=月線）+ 下軌
- **開布林**：橫盤 → 三線平行 → 表態開口
- **反轉**：頂上連 2 黑 K = 高檔反轉；底上連 2 紅 K = 低檔反轉
- **中軌上揚** = 上軌區間、回後買上漲、抱緊
- **中軌下彎** = 下軌區間、搶反彈、空手觀望
- **橫盤**：頂減碼 + 底加碼、突破箱型高 → 表態開布林

### `frank_monthly_kd_macd_precise`（月 K KD+MACD 波段長線精準版）
**raw/W08**
- 月 K、下方只放 KD + MACD、**移除所有均線**
- **進場**（全達成）：
  1. KD 圖上近月首次金叉
  2. DIF+MACD > 0
  3. MACD 綠柱縮減 or 紅柱增加
- **停損**：DIF+MACD < 0
- **停利**：KD > 70 / KD 高檔死叉 / 順向舒服想賣

## 📊 籌碼 / 短期趨勢

### `frank_broker_lookup`（常勝分點主力分點查找）
**raw/W09**
- 排除：外資分點 10+ 家、隔日沖 13 家、無地區單一券商
- SOP：`histock.tw/stock/branch.aspx?no=股票代號&day=120`
- 120 天統計 → 買超大量 + 買均價不高 + **無「一天買一天賣」慣性** + **集中大買**
- 覆蓋率 ~70% 中小型（大權值不適用、外資主導）

### `frank_credit_ratio`（券資比 = 融券/融資）
**raw/W10**
- 融資有主力混入、券資比是**散戶指標**
- 強勢股券資比攀升 = 空單當燃料續漲
- 強勢股券資比**開始下降** = 更加小心
- 只做**短期強勢股**判斷、震盪盤不適用

## 🚀 飆股操作

### `frank_daily_retracement_5ma_10ma`（日 K 回檔 5MA / 10MA）
**raw/W11**
- **飆股守 5 日**：向上開布林 = 飆股基因；洗盤陷阱（跌停/長黑但沒破 5MA）→ 別空；**真跌破 5MA** = 開始回檔
- **投信買超守 10 日**：飆股破 5 日但投信續買 → 10 日常守穩拉下影

### `frank_hot_stock_scan_daily`（找飆股）
**raw/W12**
- 兩來源：每日**週轉率 Top 1~15** + 日報**5 天後進處置注意股**
- 觀察：漲跌幅一直往上跳 + 飆股守 5 日 + KD 80 死叉（反向 KD）
- 進場：當日尾盤守住 or 隔日不開低破 5 日再守一次

### `frank_hot_stock_habit_reversal`（飆股慣性 + 反轉訊號）
**raw/W14**
- **飆股特性**：K 棒壓布林頂 + 當日回測近前日 K 低就收腳
- **進場**：太噴等不到回 5 日 → 掛**前根 K 低點附近**、停損飆股 5 日破線
- **反轉訊號**：K 棒**當日到收盤前都沒壓布林頂之上**（K 脫離布林頂）→ 微減碼、後續看橫向戰法

### `frank_hot_stock_3_5_rule`（飆股 3、5 法則）
**raw/W15**
- 連續拉紅 K（**+5% 以上**）2 天 → 小心第 **3** 天可能回檔
- 過第 3 天 → 看**第 5** 天
- 第 5 天還噴 = **妖股**
- SOP：第 3/5 天開盤留意 5m 關鍵 K、守住續強、否則守 5m 戰法一

## 🔥 K 棒 / 轉折

### `frank_sunrise_sunset_line`（日出 / 日落線）
**raw/W17**
- **日出**：連 3 根跌 K + 收腳 K + 紅 K 收過收腳 K 高 → 集體共識守日出 K 低不破
- **日落**：連 3 根漲 K + 上影 K + 黑 K 收破上影 K 低 → 集體共識守日落 K 高不過

### `frank_kd_divergence_indicator`（KD 高低背離）
**raw/W18**
- 比較**近 2 波**（不看太遠）
- **低背**：股價創新低 + KD 沒創新低 → 上漲轉折
- **高背**：股價創新高 + KD 沒創新高 → 下跌轉折
- 15m & 日 K 最常用、2m 也可但偏搶短

### `frank_reversal_precursors`（上漲看撐 + 反轉前兆）
**raw/W22**
- **加權/大盤**：5MA + 20MA、5MA 上穿 20MA = 回升確立
- 4 要點：均線扣抵蹺蹺板持續上揚 / 看撐不預設壓（守 5MA、獲利大守 20MA）/ KD 80 高檔鈍化（破 80 死叉小心）/ 有風險用鎖單
- **反轉徵兆**：爆量 K 出現**長上影** + 下一根未開高走高 + 破爆量低 → 反轉心理準備 → 短線 10EMA 破 → 前波爆量-1 破 → 反轉確立
- 反轉後拉回橫盤 → 觀察過高再攻 or 破低回升未到

## 🛡️ 加碼 / 資金管理

### `frank_add_position_defense`（加碼 & 分批觸價守利）
**raw/W16**
- **加碼原則**：想成現在空手會想介入的點位、加碼 ≤ 主單、加碼破短期戰法即出加碼單
- **主單 vs 加碼單守法**：主單飆股守 5 日、加碼單守 5m 戰法一分歧（不同層次）
- **分批觸價表**：
  | 報酬率 | 觸價設定 |
  |---|---|
  | 0~8% | 5m 戰法一破 |
  | 8~14% | 前一日 K 低 + 5m 戰法一 |
  | 15%+ | 前一日紅 K 一半 +幾 tick / 紅 K 低 / 最低守 5 日 |
- **散戶反模式**（要改）：獲利多稍跌就慌賣、賠多反而蓋牌

## ⚠️ 特殊情境

### `frank_disposal_stock_stay_or_leave`（處置股閃 or 留倉）
**raw/W13**
- **可留條件**（同時符合）：
  1. 入處置前 1~2 天日 K **爆大量**
  2. 仍守**小時 K 戰法一**
- 尤其 20 分處置盤：不可融資融券 + 全額交割 + 一天量少 → **主力處置前爆量進場、處置期間無法出貨** → 後續創波段高 / 處置後拉高機率高

### `frank_gap_retest_playbook`（跳空缺口回測）
**raw/W21**
- 缺口回測「集體共識」確認（越多越好）：短分時**背離** + **日出/日落 + 城牆挺住** + **頭肩型態** + **戰法一穿越**
- **多方缺口回測守住**：大 K 灌破 10EMA 假象、2m 低背 + 城牆低守 + 上穿戰法一 + 頭肩底右肩殺不下 → 大漲
- **空方缺口回測守住**：連紅站上假 V 轉、2m 高背 + 城牆高過不去 + 下穿戰法一 + 頭肩頂 → 下跌
- 打穿即時停損（消息面/非預期）、回測缺口進場**損點很低**

### `frank_us_stock_dump_next_day_sop`（美股大跌次日開盤 SOP）
**raw/W20**
- 開盤前：庫存是否守 15m / 小時 K 戰法一
- 觀察早盤美股期 / 富台指
- 開盤爆量觀察**爆大量城牆 K 低**、寬限到 **9:15**
- 城牆 K 低不破 → 乖離過大 + 集體共識、程式單機構買盤
- 城牆 K 低破 → 先跑、等新城牆 or 底部爆大量 + 日出再回
- **6 步大戶 vs 散戶劇本**：大戶自救 → 拉緩漲 → 均價出貨 → 全出 → KD 低檔再吃貨 → 盤整
- **特殊機會**：15m 開低走高紅 K + 精準打擊 60EMA + 紅 K 從 60EMA 拉到 10EMA = 可遇不可求

## 🎯 大小分時 & 台指期

### `frank_large_small_period_kd`（大小分時 KD 互斥觀察）
**raw/W19**
- **大分時決定方向、小分時決定時機**
- 分時搭配：留倉波段 = 日 K + 小時 K；波段次選 = 小時 + 15m；當沖 = 5m + 2m
| 大 | 小 | 判讀 |
|---|---|---|
| 金 | 金 | 最強、多方共識 |
| 金 | 死 | 洗盤震盪、等小分時金叉再進 |
| 死 | 金 | 反彈遇壓 |
| 死 | 死 | 別碰 |

### `frank_taifex_15m_2m_combo`（台指 15m + 2m 戰法一）
**raw/W24**
- 15m+ / 2m+ = 做多；15m- / 2m- = 做空；互斥 = 觀望
- 停損（獲利未拉）：破小分時戰法一
- 停利（獲利拉開）：守大分時戰法一
- 互斥後等 15 遇 60EMA 反向分歧 + 2 分破戰法一再進

### `frank_taifex_hedge_lock`（台指期對鎖鎖單）
**raw/W23**
- **多單 +150~200 點以上**獲利、遇 15 分高背 + 日落 → 下對等空單對鎖
- 空單停損：15 高背後居然過高
- 15 分歧 → 空單停利、多單續抱
- 15 下穿 → 多單停利、對鎖空單續賺
- **需大數據方案 + 熟轉折 + 台指有獲利經驗**

### `frank_1m_2m_scalping`（1m / 2m 當沖）
**raw/W25**
- 趨勢判斷：當日均價線斜率為正 + 大戶一層比一層買超 + 5m 符合戰法一
- 1m 慣性沿 10EMA 上 vs 被 10EMA 壓
- **兩種進場**：
  - 慣性法：沿 10EMA 上漲、回檔 10EMA 進場；被壓則反彈 10EMA 進場
  - KD 法：1m KD 低檔 20~40 上鉤金叉 + 五檔戰法符合 → 進場（配鳥嘴/分歧更佳）
- **停利紀律**：大單狂敲急拉 + 離 10EMA 遠 → 分批停利（強股必回 10EMA）
- 不熟戰法/無法盯 1m 者 → 別做當沖

## 💎 權證

### `frank_warrant_big_player_signal`（識別大戶進場權證）
**raw/W26**
- 在外流通 ≤ 500 突然**爆大量 3000+ 張** = 大戶進場（散戶錢不夠）
- 在外流通滿後再爆大量 = 大戶退場

### `frank_lottery_warrant`（樂透權證）
**raw/W27**
- 條件：
  - 價格 ≤ **0.2 元**
  - 到期日 > **90 天**
  - 大戶進場但還未出場 OR 高價股腰斬又腰斬
- 金額只能買小、**不可重壓**
- 高價股腰斬又腰斬 → 3 個月內通常有反彈
- 案例：0.09 進場 100 張、2 天漲 65%、最差賠 9 千

### `frank_warrant_advanced`（大戶權證進階）
**raw/W28**
- **固定金額而非固定張數**（均注）
- 大戶權證**隔日再買**：續漲 = 方向對；跌回測有撐 = 買比大戶低
- **加權/台積權證** 大戶進場勝率高
- **高槓權證**：大戶常先知有「內褲 X」→ 只當樂透買、不重壓

## 📰 時效性
### `raw/W29`：新春年假 2025 特報（時效性新聞快照、非戰法）
