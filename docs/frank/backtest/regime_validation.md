## 結論（照三軸標準誠實評）

1. **機制跨年全年皆正但薄**：+1.05~+1.92%/筆、WR 40~45%、遠低於 65% 三軸門檻 → **不可無腦全 universe 部署**
2. **2026 的 +6.57% 主要是 regime 紅利**（AI 大多頭）、非機制 alpha
3. **加權 20MA gate 幾乎無改善**（WR +1~3pp）→ 弱季虧損不是大盤方向問題、是**族群/個股層面** → 呼應老師「選股不選市」
4. **實戰定位**：Frank 機制 = **執行紀律層**（何時進、何時出、避免追高殺低），alpha 要靠**選股層**（老師名單當年度有效性）。(e) 的 60.8% WR / +9.45% 是「你已選對的股 + Frank 紀律」的組合效果 — 這才是本次復盤的真正結論：**選股維持現在的來源、執行換成 Frank 紀律**。
5. 依 `feedback_detector_regime_conditional`：此機制掛 regime-conditional 標籤、僅在「老師名單 + 多頭確認」時啟用。
