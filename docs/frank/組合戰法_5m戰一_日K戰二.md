# 組合戰法：5m 戰法一 + 日 K 戰法二

**定位**：主戰法 = **日 K 戰法二**（決定選標的 + 方向 + 抱單）、5m 戰法一 = **進場時機切入**。

**Frank 原話出處**：
- `raw/04 戰法二波段延伸`：「大格局確認完畢後、進場點還是會建議日 K 做切入會比較順手」+ 「5 分戰法一切入也 OK」
- `raw/07 常犯錯誤 #4`：「保守者選 **60EMA 均線斜率 30~45° 上揚 + 股價回測 + 分歧**」
- `raw/08 虧損最小 Setup 1+2`：這個組合 = 保守進場的黃金組合
- `raw/16 簡易戰法`：進場用 5m、防守用日 K

## 🎯 完整流程

### Step 1：日 K 戰法二選標的（過濾）
- 還原日 K + 布林通道 + 20MA 月線
- **必要條件**：
  - 月線（中軌）**上揚 30° 以上**（`raw/08`）
  - 股價維持**布林上軌區間**（頂 ~ 中軌）
  - 加分：週 K 20MA 也上揚（戰法二週 K 延伸）
- **排除**：中軌走平/下彎、股價位於下軌區間

### Step 2：等回檔訊號（時機來源）
選一個當進場觸發（越保守選越低者）：

| 觸發 | 位置 | 保守度 |
|---|---|---|
| **回測 20MA（月線）觸價** | 中軌本身 | 最保守、損最小 |
| **日 K 中軌分歧** | 中軌上方分歧 | 保守（`raw/08` Setup 2）|
| **回落 5MA 再上** | 5MA 上方 | 中（飆股適用）|
| **突破布林頂再回測**（回後買上漲）| 頂附近 | 積極 |

### Step 3：5m 戰法一切進場點（精準）
到觸發日 → 切 5m + 10EMA + 60EMA + KD

**進場條件全達成**：
1. 大戶**買超持續增加** or **賣超收斂**（戰法一鐵則 raw/06）
2. 5m 10EMA 上穿 60EMA（or 已在上、回測 60EMA 分歧）
3. **60EMA 有斜率**（≥ 30°、非橫向震盪）
4. **後一根 K 收超前一根**（慣性改變日出）
5. 5m KD **不在向下**（`raw/W06`）
6. 五檔戰法無假掛單（`frank_5tick_fake_order`）

### Step 4：停損（雙層）

| 層 | 條件 | 出場 |
|---|---|---|
| **短線層（獲利未拉開）** | 破 5m 戰法一（10EMA 下穿 60EMA）| 出主單 |
| **波段層（獲利拉開）** | 日 K **連續 2 日收盤跌破月線** | 出主單 |
| **絕對層** | 20MA 開始**下彎** | 一定出 |

### Step 5：抱單 + 加碼

**抱單**：股價維持布林上軌區間就抱、每天不理盤中震盪、設**月線下幾 tick 觸價單**保底。

**加碼**（`frank_add_position_defense`）：
- 主單守日 K（月線 or 飆股 5MA）
- 加碼單想成「現在空手會進的點」→ 每次**回測月線或 5MA 分歧**時加
- **加碼 ≤ 主單**
- 加碼破 5m 戰法一 → 立刻出加碼單、主單續抱

### Step 6：停利

| 觸發 | 動作 |
|---|---|
| 布林頂連 2 黑 K 壓在頂上 | 減碼 |
| 飆股（開布林後）破 5MA | 分批出 |
| 布林頂 → 中軌回跌時 | 減碼 |
| 中軌回漲時 | 加碼 |
| 月 K KD > 70 or 高檔死叉 | 完全出（升級戰三停利） |
| 順向獲利大到心情爽 | 出（Frank 官方停利 #4）|

## 🚨 常見錯誤（本組合特有）

1. **日 K 中軌沒上揚就切 5m 戰法一**
   → 只是均線上穿、不是真戰法二、易兩層皆破
2. **5m 戰法一破就砍主單**
   → 錯層次！主單守日 K、5m 破只出加碼單
3. **獲利拉開後還盯 5m 判斷**
   → 早該升級守月線、盯 5m 反而過度緊張砍在洗盤
4. **距 20MA 太遠追進**
   → 保守進場 = 回測 20MA 附近、不追噴出
5. **布林頂連 2 黑不減碼**
   → 高檔反轉訊號、繼續抱可能反轉大回吐

## 💡 為什麼這組合好用

- **戰法二負責選對股 + 抱得住**（月線上揚 = 中期趨勢確立）
- **5m 戰法一負責買在對的點**（避免追高、進場損最小）
- 兩層停損（5m + 日 K）= 進場損很小、但抱得夠久吃波段
- 對應 `raw/08 保守進場 Setup 1+2` 的實戰組合
